# Lantern Ink — M4, the window

What "the window is done" means (ARCHITECTURE §11, D20): **Ink replaces
Boxy SVG for Lantern's icons.** M4 is done when every box here is ticked
by Alva, or struck by her. A box is something she can open, click and
look at.

Decided with Alva, 2026-10-07:
- **The bar:** Boxy's replacement. All twelve tools of ARCHITECTURE §8,
  the object tree, fill and stroke, the icon aids, and a menu row for
  every operation the MCP server already has.
- **The order:** six slices, the shell first. Each ends with something
  to open and poke at.
- **The look (D12):** LS3's theme, layout, chrome and controls are
  copied into `ink-app`. No other project changes; a shared crate can
  come once we see what the two apps really share.
- **The name:** the first deploy takes `~/.lantern/bin/lantern-ink` from
  the May prototype.
- **The pen (D17):** click points, bend the segments after. No
  click-drag handles while placing.

Rules that hold in every slice (ARCHITECTURE §8): text is 18 px at
least, targets are generous, surfaces have the sheen and 2 px lines, no
help toasts, draw once and adjust forever, the Box owns every tool and
selection setting, and nothing holds a frame up (tiles, files and
pickers work off the window's thread).

## a — The shell and the viewer

The window, in LS3's look, showing drawings.

- [ ] `lantern-ink` opens maximized, with its own log
      (`~/.lantern/log/lantern-ink.log`; a panic leaves `PANIC:` there)
- [ ] The title bar: the menus, and `L A N T E R N   I N K` with the app
      icon on the right
- [ ] The menus have their final shape: File, Edit, Object, Path, Text,
      View. Rows whose work comes in a later slice are there, greyed
- [ ] The look is LS3's: warm dark panels with the sheen, gold accent,
      2 px rules, the rainbow strips beside the toolbar and above the
      status bar
- [ ] The toolbar: a tile for each of the twelve tools, the one in hand
      ringed in gold, its name and key under the pointer, the shape
      tools sharing a slot with a flyout
- [ ] Tool keys pick tools (V, A, P, R, T, G, I, H, Z)
- [ ] Document tabs: the showing one in gold, `•` on one with changes,
      `×` to close, `+` for a new drawing
- [ ] The canvas draws the drawing with Ink's own renderer, sharp at
      every zoom, on transparency checks with the page's edge marked
- [ ] What's drawn past the page's edge shows too, dimmed by nothing:
      it's there to be grabbed
- [ ] The wheel pans, Ctrl+wheel and a pinch zoom toward the pointer,
      the middle button and Alt+drag move the view
- [ ] The Hand tool drags the view; Space held does too, whatever tool
      is in hand
- [ ] The Zoom tool: a click zooms in at the pointer, Alt+click out
- [ ] View menu: Zoom In, Zoom Out, Fit to Window, Actual Size
- [ ] Zooming never waits: the old picture stretches until the sharp
      one lands
- [ ] The status bar: the version, the drawing's name, where the
      pointer is in the drawing's own units, the page's size, the tool
      in hand, results in gold; on the right the zoom buttons and the
      CLAUDE pill (kept out until M5)
- [ ] The right panel's frame: drag its edge to resize (260–520 px),
      double-click for 400, remembered between runs
- [ ] File > New makes a drawing the size of the one showing (24 × 24
      with none)
- [ ] File > Open asks with Lantern's file picker; a file dropped on
      the window, or named on the command line, opens too
- [ ] A file that's open already shows its tab instead of opening twice
- [ ] File > Open Recent, with the ten latest, and Clear Recent
- [ ] File > Save and Save As write the `.svg`. One opened and saved
      untouched is the same bytes
- [ ] A new drawing nothing has been done to closes without a
      question, and gives its tab to the first file opened
- [ ] A file Ink can't read says why in the status bar

## b — The object tree, the Pointer, undo

Selecting, arranging, and the first edits by hand.

Decided with Alva, 2026-10-08:
- **A drag shows the real drawing, live:** exact stacking, shadows and
  clips while it goes, and only the tiles it touches drawn again. The
  outline always keeps up with the pointer; the artwork under a wide
  shadow may trail (measured in ARCHITECTURE §8).
- **Scaling by the handles keeps a stroke's width:** the shape's own
  numbers change, and a 2-unit outline stays 2 units. "Scale strokes"
  in the Box turns scaling on, for resizing a whole icon.
- **Resized, lines stay as they are** (built in b3, hers to look at):
  besides the stroke's width, its dashes and a rect's corner rounding
  stay too; a circle stretched one way becomes an ellipse. A rect
  scaled across the way it's turned, and anything under a shadow, can
  only be scaled as a picture, stroke and all.
- **Four pieces:** b1 the groundwork in the core (gestures, and tiles
  kept across an edit), b2 the tree, b3 the Pointer, b4 the menus and
  the Box. Each is committed and pushed once it's tested and deployed;
  she looks at each one that has something to see before the next.

- [ ] Gestures in the core: a drag previews without touching the
      drawing, and lands as one step of history (ARCHITECTURE §4.3)
- [ ] The object tree lists what `doc_info` does, front to back: each
      row its kind, its label (or its `id`), an eye and a lock
- [ ] Groups open and close; what's in them is indented
- [ ] A click selects, Ctrl+click adds or takes away, Shift+click
      takes the run between
- [ ] Double-click a row to rename it (its `ink:label`)
- [ ] Drag rows to restack them, or into and out of groups
- [ ] The lock is `ink:locked`: a locked row refuses every edit
- [ ] The Pointer: a click on the canvas selects what's there, Shift
      adds, a drag on nothing draws a marquee
- [ ] Double-click goes into a group; Escape comes back out
- [ ] The selection's box has handles: drag inside to move, a corner or
      a side to scale (Shift keeps the shape, Alt about the middle),
      outside a corner to turn (Shift by 15°)
- [ ] The arrow keys nudge (Shift: by ten)
- [ ] Handles and outlines are the same size at every zoom
- [ ] Only the tiles an edit touches are drawn again
- [ ] Edit > Undo and Redo, each named for its step ("Undo Move")
- [ ] A tab with changes shows `•`; closing it asks "save first?", and
      quitting with changes lists them and asks (built with slice a,
      but nothing can change a drawing until this one)
- [ ] Edit > Cut, Copy, Paste (as SVG, so it pastes into other apps),
      Duplicate, Delete, Select All, Deselect
- [ ] Object > Group, Ungroup, Bring Forward, Send Backward, To Front,
      To Back
- [ ] Object > Align (left, centre, right, top, middle, bottom) and
      Distribute, against the selection or the page
- [ ] Object > Flip Horizontal, Flip Vertical, Rotate 90°
- [ ] The Box shows the selection's place and size, to type into
- [ ] The Box's "Scale strokes": off, a shape scaled by its handles
      keeps its stroke's width; on, the stroke scales with it
- [ ] Right-click on the canvas: the selection's menu

## c — Paint and the shape tools

- [ ] The right panel's Fill and Stroke: none, a colour, or a gradient,
      each with its opacity
- [ ] The colour picker: LS3's, with hex to type and the palettes
- [ ] Stroke: width, caps, joins, dashes
- [ ] The whole node's opacity
- [ ] Rectangle, Ellipse, Line and Polygon tools: drag to draw (Shift
      keeps it square, Alt from the middle)
- [ ] A drawn shape keeps its handles: a rect's corners round by
      dragging, a polygon's sides and a star's points are set in the Box
- [ ] A new shape is painted as the last one was
- [ ] The Box holds the tool's settings, then the selected shape's

## d — The Node tool and the Pen

- [ ] The Node tool shows a path's anchors and handles
- [ ] Drag an anchor, a handle, or a segment (to bend it)
- [ ] Double-click a segment for a new anchor; Delete takes anchors out
- [ ] Smooth or corner an anchor; break a path at one; join two ends
- [ ] A shape that isn't a path yet becomes one when its anchors are
      first touched
- [ ] The Pen: click points, close on the first, Enter or Escape ends;
      then bend the segments (D17)
- [ ] Path > Union, Subtract, Intersect, Exclude
- [ ] Path > Outline Stroke, Simplify, Reverse, Object to Path

## e — Text, gradients, the eyedropper

- [ ] The Text tool: click to place, type on the canvas, Enter for a
      new line
- [ ] The Box: family (the fonts installed, each in its own face),
      size, bold, italic, line height, alignment
- [ ] A font that isn't installed says so, and which one drew instead
- [ ] Text > Text to Path
- [ ] The Gradient tool: drag across a shape for a linear one, from its
      middle for a radial one; the ends stay as handles
- [ ] A gradient's stops: add, move, recolour, remove, on a bar in the
      Box
- [ ] The Eyedropper takes a colour from the canvas into the fill
      (Shift: the stroke)
- [ ] Object > Clip, Release Clip
- [ ] Object > Drop Shadow and Blur, with their settings in the Box

## f — The icon aids, and not losing work

- [ ] A pixel grid when zoomed in far enough to see it
- [ ] Drags snap to whole and half units, and to other shapes' edges
      and middles, showing what they landed on (View > Snapping)
- [ ] Guides: dragged out of the rulers' edges, kept in the file (D19)
- [ ] The Lantern preview strip in the right panel: the drawing at 16,
      24, 32, 48 and 64 px, as Lantern's apps will draw it
- [ ] File > New… asks for a size, with the icon sizes as presets
- [ ] File > Page…: the page's size and its viewBox, with "fit the
      drawing to it"
- [ ] File > Export…: a clean `.svg` to ship, or a PNG at one or
      several sizes
- [ ] Edit > Tidy, saying what went
- [ ] Autosave: unsaved work is copied aside as it's made, and offered
      back after a crash
- [ ] Edit > Preferences
- [ ] Everything a slice left greyed in the menus is lit or gone
